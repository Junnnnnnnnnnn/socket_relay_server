Climb Room Test

테스트: roomFull (최대 4명, payload { room, maxPlayers }, controller만 카운트) · joinedRoom (참가자 리스트 브로드캐스트) · roomPlayerCount (count) · disconnect-room (방 전체 강제 종료, 신규) · 재-joinRoom 보호(이미 입장한 본인 호출은 정원 체크 제외, 신규)
테스트 시나리오
① + Display → 디스플레이 1개 먼저 연결 (참가자 카운트에 포함되지 않음).
② + 4 Controllers → 같은 방에 컨트롤러 4개 정상 입장 (모두 연결, 참가자 리스트 4명).
③ + 5번째 (full 테스트) → 5번째 컨트롤러만 roomFull 이벤트 수신, 빨간 보더 + "ROOM FULL (max 4)" 표시. 나머지 4명 + Display 영향 없음.
④ 재-joinRoom 보호 테스트 → ②에서 이미 입장한 컨트롤러의 joinRoom 재전송 버튼 클릭. 정원이 가득 차 있어도 거부되지 않고 정상 처리(이름 변경/재연결 케이스 보호).
⑤ 룸 전체 disconnect → disconnect-room 이벤트 emit. 방의 모든 소켓(컨트롤러 + 디스플레이)이 한 번에 끊김.
※ climb은 display가 먼저 연결되어야 startGame 가능. 참가자 카운트는 controller만 포함됩니다.
