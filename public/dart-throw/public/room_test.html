Dart Room Test

테스트: roomFull (최대 4명, payload { room, maxPlayers }) · joinedRoom (참가자 리스트 브로드캐스트) · roomPlayerCount (count) · disconnect-room (방 전체 강제 종료) · 재-joinRoom 보호(이미 입장한 본인 호출은 정원 체크 제외)
테스트 시나리오
① + 4명 한번에 → 같은 방에 4개 클라이언트 정상 입장 확인 (모든 카드가 연결됨, 참가자 리스트 4명).
② + 5번째 (full 테스트) → 5번째 카드만 roomFull 이벤트 수신, 빨간 보더 + "ROOM FULL (max 4)" 표시. 나머지 4명은 영향 없음.
③ 재-joinRoom 보호 테스트 → ①에서 이미 입장한 카드의 joinRoom 재전송 버튼 클릭. 정원이 가득 차 있어도 거부되지 않고 정상 처리(이름 변경/재연결 케이스 보호).
④ 룸 전체 disconnect → disconnect-room 이벤트 emit. 방의 모든 소켓이 한 번에 끊김.
